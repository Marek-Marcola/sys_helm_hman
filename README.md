helm hman
=========

Helm chart management tools.

Install
-------
Install:

    hman.sh --inst -x
    -- or --
    hman.sh --anpb -x
    -- or --
    cp -fv hman.sh /usr/local/bin/hman.sh
    cp -fv hman.sh /usr/local/bin/hman-exec.sh
    cp -fv zlocal-hman.sh /etc/profile.d

    mkdir -pv /usr/local/etc/hman.d
    mkdir -pv /usr/local/bin/alias-hman

Verify:

    hm --ver

Help:

    hm --help
